# Saved student context

These files are blank in the shared version. Update them in your personal copy.

- [Student profile](STUDENT_PROFILE.md): preferences and practical constraints.
- [Dashboard](DASHBOARD.md): course registry and current priorities.
- [Memory](MEMORY.md): reusable corrections and decisions.
- [Handoff](HANDOFF.md): the last task and where its detailed state lives.

Keep them short. Put course knowledge and practice evidence in the course folder. See [progress workflow](../workflows/PROGRESS.md) for updates.
