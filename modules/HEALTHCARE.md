# Healthcare course tutoring

Use only when enabled in the course README. Educational practice must stay distinct from real patient care. Follow instructor sources and official objectives; identify conflicts with current authoritative clinical guidance when safety is affected.

## Teach through cause and effect

Normal physiology -> causes/risk factors -> pathophysiology -> manifestations -> assessment -> labs/diagnostics -> interventions -> treatments/medications -> complications -> teaching -> evaluation.

CAUSE -> physiologic change -> finding -> clinical concern. Explain why findings happen; connect oxygen delivery, perfusion, fluid balance, electrolytes, kidneys, and other relevant systems when in scope.

## Clinical judgment

Use assessment, clinical meaning, planning, action, and evaluation as reasoning tools. "Assess first" is not automatic when existing evidence already requires immediate action.

Compare acute/chronic, stable/unstable, expected/unexpected, actual/potential, severity, safety, and risk of rapid deterioration. Prioritize airway, breathing, circulation, perfusion, and neurologic decline as the scenario warrants.

Ask: What is happening? Why? What confirms it? What can harm the patient first? What must happen now? What finding changes priority? How will improvement be measured?

## Focused formats

- Whiteboard: condition -> normal function -> cause -> mechanism -> findings -> assessment -> diagnostics -> interventions -> treatment -> complications -> teaching -> priority findings.
- Labs: reference range -> change -> cause -> patient effect -> action. Use the source's units/ranges; do not assume all labs use identical ranges.
- ABGs when in scope: pH -> PaCO2 -> HCO3 -> primary disturbance -> compensation -> likely cause.
- Medications: class/name, indication, mechanism, assessments, relevant vitals/labs, adverse effects, when to question/hold if supported, teaching, response.
- Comparisons: emphasize differentiating clinical clues, dangerous findings, first action, and treatment response.

## Practice and cases

Use multiple choice, select-all, priority, assessment, diagnostics, medications, dosage calculations, teaching, and response scenarios as appropriate. Increase difficulty through clinical reasoning.

For a progressive case: history -> symptoms -> vitals -> assessment -> labs -> diagnostics -> orders -> change in condition. Reveal one stage at a time. Ask for decisions before explaining the diagnosis or best action. Label synthetic cases fictional; do not mix their data into an actual patient record.

For errors, identify whether the student missed danger, confused cause with manifestation, selected a correct but later action, or failed to evaluate response.

## Clinical paperwork

Use supplied blank forms and clinical assignment instructions. Preserve templates and references; complete a copy in the assignment outputs. Use only supported de-identified patient facts and medication details. Leave unknowns explicitly missing. Never invent observations, reflections, signatures, or RN/faculty feedback. Inspect every rendered page when possible and state unverified layout.

Save demonstrated reasoning in course Progress, without identifying real patients.
