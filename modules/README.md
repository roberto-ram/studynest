# Optional subject guidance

The shared system works for any course without a subject module.

## Select modules from evidence

Use the student's description, course title, syllabus, and objectives. A health-related keyword in an unrelated course is insufficient.

When those sources clearly identify nursing, medicine, or another healthcare program/course:

1. Automatically add `modules/HEALTHCARE.md` to the course README's enabled modules and cite the classification evidence.
2. Create `case-studies/` in that course with a short README explaining progressive cases, fictional practice, and source priority.
3. Use the blank [case template](../templates/healthcare/Case%20Study.md) when a case is requested.
4. Add `clinical/` only when clinical assignments or simulations are actually needed.

Tell the student what was enabled; no extra approval is needed for this reversible course organization. If course identity is ambiguous, leave the module disabled, proceed with general setup, and ask one short clarification within onboarding.

For other disciplines, use [subject adaptation](SUBJECT_ADAPTATION.md) only when helpful. Case studies for business, law, engineering, or education can also be added on request; healthcare is not the only possible scenario-based discipline.

Do not enable every module or copy all subject instructions into the global memory.
