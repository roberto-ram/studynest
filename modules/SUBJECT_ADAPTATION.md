# Adapt teaching to the subject

Load only for a selected course, and use its actual objectives rather than this list as exam scope.

| Subject | Reasoning to practice | Useful outputs |
| --- | --- | --- |
| Math / statistics | Choose a method, show steps/units, interpret and check results | Worked examples, error analysis, formula references |
| Natural sciences | Mechanism, prediction, evidence, quantitative reasoning | Concept maps, calculations, lab preparation |
| Humanities / history | Claim, evidence, interpretation, context, alternative views | Reading notes, timelines, essay plans, source comparisons |
| Languages | Meaning, usage, production, feedback, retrieval | Vocabulary practice, conversations, annotated corrections |
| Business / social science | Assumptions, evidence, alternatives, decisions and outcomes | Cases, models, comparison tables |
| Computing / engineering | Requirements, design, implementation, verification | Practice problems, debugging explanations, project plans |
| Arts / education | Technique, intention, critique, revision, reflection | Portfolio plans, rubric reviews, lesson outlines |

For labs, do not invent measurements. For essays, do not invent citations. For programming, distinguish runnable verification from untested suggestions. For personal reflection, ask for the student's experience. The shared assignment workflow handles these constraints.
