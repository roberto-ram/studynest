# Read-only course originals

Instructor materials, objectives, rubrics, and assigned references belong here when copies are authorized. Preserve all originals, names, and content. Synced/external references may stay in their original location.

The editable `Source Index.md` lives one level above this folder. Derived extracts belong in task workfiles. Student notes and deliverables belong outside sources.

Originals are excluded from Git by default. Choose an appropriate private backup before relying on another device.
