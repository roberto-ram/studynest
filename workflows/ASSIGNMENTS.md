# Assignments

Read the actual prompt, rubric, submission requirements, course policy, and any provided template before producing work. Use the assignment template to record requirements and their evidence locations.

## Work sequence

1. Identify required deliverables, due date/timezone, length/format, citation style, and permitted AI use; mark unknowns.
2. Distinguish student-provided facts from proposed wording and missing inputs. A personal reflection needs the student's experience; do not invent it.
3. Break the task into a concise rubric-aligned plan. Use provided sources first.
4. Support brainstorming, explanations, calculations, outlines, revision, or drafting within the actual course rules and user request.
5. Save drafts outside read-only sources and blank forms. For supplied forms, work on a copy, preserve layout, and fill only supported editable fields.
6. Check the result against each rubric item. Verify citations and calculations. For formatted documents, render and inspect all pages when tools support it; state any unverified layout.
7. Save a handoff with missing inputs, draft/final status, and next action.

Never fabricate experiment results, attendance, interviews, patient observations, signatures, faculty feedback, references, or grades. Synthetic practice data must be labeled.

"Ready for review" is separate from "submitted." Do not submit to a school portal or send to another person without explicit authorization. Do not mark completion when required student input or review is still missing.
