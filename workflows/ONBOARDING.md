# Onboarding

First verify access: name the workspace root and read a known file. Check whether local files can be changed. With writing access, create and read back a harmless workfile; remove only that test file. Without writing access, explain the manual-save path. Never pretend a project attachment grants disk access.

Ask only for missing information, in no more than five bundled questions:

1. Courses, program, term, and subdivisions they want.
2. Syllabus, objectives, exam scope, rubrics, lectures, and assigned readings available.
3. Immediate goal, confirmed deadlines, and available study time.
4. Explanation/practice preferences and accessibility needs they choose to share.
5. Their personal copy/backup location and whether this is a blank template or an already personalized workspace.

Existing answers count; do not ask them again. Set up what is known while marking gaps.

## Create the workspace

1. Complete the profile and course registry without inventing details.
2. Copy templates/course into a new course path. Replace template labels using supported course facts. Keep untouched template copies reusable.
3. Use SOURCE_INTAKE to index materials. Start with a minimal course, not empty folders for every possible future task.
4. Create exam, unit, and assignment folders only when needed from the corresponding templates.
5. Select domain modules using modules/README.md. For a clearly healthcare course, automatically add clinical case support and explain the choice.
6. Build a sourced priority map when objectives/scope exist. Otherwise mark the scope provisional.
7. Save a handoff and a short next-action list. Show the student where context lives.

Do not push personalized changes to the shared template. A local clone still has its original remote until explicitly changed.

## Finish setup

Give a short orientation, the current highest-value action, and the resume prompt. Verify a fresh chat can recover the chosen course, source priorities, progress, and next step. Do not claim a particular AI product has been tested unless it actually has.
