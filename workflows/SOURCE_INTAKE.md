# Source intake

Use course materials first. Default authority: assignment instructions/rubric and official scope for the task; instructor lectures/notes and current course notices; assigned textbooks/readings; reputable supporting references. The course README may record a more specific source order.

## Intake steps

1. Inventory new files by name, role, course, topic, date/version, and access status. Read enough to classify; do not fully ingest every large file.
2. Preserve originals in place. Copy only when authorized. Never rename, move, edit, or delete imported/synced references. Avoid duplicates; record shared references once.
3. Update the course Source Index using stable source IDs such as S001. Include path/URL, role, priority, objective/topic coverage, page/slide/section clues, and readable/partial/missing status.
4. Extract only relevant text into workfiles when needed. For an extract, record original path, version/hash when practical, page mapping, extraction method, and limitations. Recheck the original if changed.
5. Link a unit or exam to source IDs and relevant locations. Track external files that a new machine will need.
6. Flag conflicts, missing pages, unreadable scans, and duplicate versions. Do not silently merge inconsistent statements. Never cite a source you did not actually read.

## Scope and claims

Use official objectives to define required abilities and official scope to define included topics. Label extra context as supporting information. Distinguish instructor expectations from current external guidance.

Preserve instructor-provided video links with title, topic, URL, and source. Videos supplement the required materials.

If current facts require external verification, use appropriate authoritative sources and date the lookup. For healthcare safety conflicts, explicitly separate the course statement from current clinical guidance; do not treat an unsafe statement as a care instruction.

After intake, update affected priority maps and handoffs; do not recreate all notes unless a change makes them inaccurate.
